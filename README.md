## Development process

1. Read the requirements and examples.
2. Plan the program before coding.
3. Write my own first attempt.
4. Test normal, boundary, and invalid inputs.
5. Review and improve the implementation.
6. Document what I learned.
7. Commit the completed work with a meaningful message.
